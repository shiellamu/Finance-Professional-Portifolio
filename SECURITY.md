# Security

## Reporting a security issue

If you discover an exposed credential, private information or other security concern in this portfolio, please contact **shiellamu@gmail.com** and do not publish the sensitive material in an issue.

## Public-data policy

This repository is intended for public professional presentation. Confidential employer, donor, partner, client and personally identifiable information must not be committed.

Before publishing, use `.github/SECURITY_CHECKLIST.md`.

## Credential safety

Do not commit passwords, API keys, access tokens, private keys or other authentication material. Certificate evidence must be authentic and should exclude unnecessary sensitive identifiers.
