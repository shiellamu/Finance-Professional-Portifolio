# Finance Interview Question Bank

## Accounting
- Walk through the accounting cycle.
- How would you investigate an unreconciled balance?
- Explain the purpose of a bank reconciliation.
- How do accruals and prepayments affect financial statements?

## Financial Analysis
- How would you explain a material variance?
- Which financial ratios would you review and why?
- How would you assess cash-flow performance?

## Controls & Audit
- Describe a control you would introduce around payments.
- How would you document and resolve an exception?
- What evidence would you retain for an audit?

## Excel & Analytics
- Which Excel functions do you use for finance analysis?
- How would you validate a dataset before reporting?
- How would you turn transaction data into a management dashboard?

## STAR practice
Prepare truthful Situation, Task, Action and Result examples from your own experience or clearly label practice scenarios.
