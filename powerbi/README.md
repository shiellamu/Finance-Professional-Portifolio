# Power BI Finance Portfolio

## Dashboard build specification

The repository now has the complete data and KPI specification needed to reproduce the dashboard layer in Power BI.

### Dashboard 1 — Financial Performance

KPIs:
- Revenue
- Gross Profit
- Net Profit
- Gross Margin
- Operating Margin
- Current Ratio
- ROE

Visuals:
- Revenue and net-profit trend
- Margin trend
- Liquidity trend
- KPI cards

### Dashboard 2 — Budget vs Actual

KPIs:
- Budget revenue
- Actual revenue
- Revenue variance
- Budget expenses
- Actual expenses
- Expense variance
- Contribution

Visuals:
- Monthly budget vs actual revenue
- Monthly budget vs actual expenses
- Contribution trend
- Material variance table

### Dashboard 3 — Finance Transactions

KPIs:
- Income
- Expenses
- Contribution
- Expense mix

Visuals:
- Monthly contribution
- Expense by category
- Expense by department

### Dashboard 4 — Bank Reconciliation

KPIs:
- Matched items
- Deposits in transit
- Outstanding cheques
- Bank-only items

Visuals:
- Exception category
- Exception value
- Reconciliation status

> A native `.pbix` file cannot be generated reliably from this environment. The repository therefore documents the Power BI-ready model, measures and visual specification without pretending that a PBIX file exists.

Never publish confidential employer, donor, partner or client data.
