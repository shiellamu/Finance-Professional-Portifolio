## Evidence intentionally kept separate

These items require the user's own verified source material before publication:

- Final CV PDF
- Original certificates
- Verified employment documentation
- Real professional project evidence
- Native Power BI PBIX files, if later created personally
- Custom domain, if desired

## Publishing rule

Fictional practice work must remain clearly labelled as practice work. Confidential employer, donor, partner and programme information must never be uploaded.

## Definition of portfolio completion

The **public portfolio build is complete** when the repository structure, website, projects, datasets, analysis, Excel evidence and dashboard specifications are in place.

Future additions are evidence upgrades, not unfinished core portfolio architecture.
