# Finance Projects

A curated collection of public-safe finance case studies demonstrating practical accounting, analysis and reporting skills.

## Flagship cases

1. Financial Statement Analysis
2. Budget vs Actual
3. Bank Reconciliation
4. Finance Data Analysis

## Evidence standard

Every project should clearly identify:
- the business question;
- the dataset and whether it is fictional, anonymised or public;
- the methodology;
- key calculations or controls;
- findings and limitations;
- tools used.
