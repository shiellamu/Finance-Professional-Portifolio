# Finance Dashboard Model

## Purpose

This case study defines a management dashboard designed to bring budget performance, cash, forecasting and exceptions into one decision-support view.

The model is designed around the principle:

**Inputs → Calculations → Controls → Dashboard → Management commentary**

## Dashboard sections

### 1. Financial performance

- Budget
- Actual
- Variance
- Utilisation
- Forecast
- Forecast variance

### 2. Cash and liquidity

- Opening cash
- Expected receipts
- Planned payments
- Projected closing cash
- Minimum cash threshold
- Funding gap indicator

### 3. Variance drivers

Show the largest absolute and percentage variances, with explanations and action owners.

### 4. Commitments

Track:

- open commitments;
- expected invoices;
- remaining budget;
- forecast exposure.

### 5. Compliance and exceptions

Track unresolved:

- reconciliation items;
- documentation exceptions;
- partner reporting issues;
- donor-compliance follow-ups.

## Suggested KPIs

| KPI | Purpose |
|---|---|
| Budget utilisation | Measures expenditure against approved budget |
| Forecast variance | Highlights expected year-end position |
| Cash coverage | Indicates available liquidity relative to planned payments |
| Commitment ratio | Shows budget exposure from open commitments |
| Exception count | Tracks unresolved finance issues |
| Reporting timeliness | Monitors finance reporting discipline |

## Dashboard design principles

- Keep the management view concise.
- Make exceptions visible.
- Link each material issue to an action.
- Separate actual results from forecast assumptions.
- Use synthetic/anonymised data for portfolio demonstrations.
- Preserve an auditable path from dashboard figures back to source data.
